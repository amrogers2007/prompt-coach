Prompt Coach — Settings

Add your own Anthropic API key to turn on AI-improved prompts. Your key is stored only in your browser and is sent straight from your browser to Anthropic — it never passes through any server of ours, and usage is billed to your Anthropic account.

Don't have a key yet? Go to console.anthropic.com → API Keys and create one. You'll need to add a small amount of credit — a prompt rewrite costs a fraction of a cent.

The key powers the refresh button on the Prompt Coach card. Without one, the on-page suggestion can't run; the free, offline rules still run quietly in the background to build your progress view.
