# History: early planning notes

These documents were written before Prompt Coach became a Claude plugin, when the plan was a browser extension.
They are kept as a record of how the idea developed: the first vision, the options considered, the first
prototype's scope, and the open questions at the time. They are not a description of the product today.

The code they refer to (`extension/`, `playground/`, `dashboard/`, `server/`, `tests/`) was removed from the
repository and remains only in its history.
